title: Things I made for my terminal
date: 2026-11-12

I live in the terminal, so a lot of what I build ends up there.

- [tot](https://github.com/vic/tot) is my own dungeon-crawler auto-shooter, clearly inspired by Diablo, Doom, Halls of Torment and Vampire Survivors. It is made for agentic gaming: ask a coding agent for a new adventure world, or to spawn pals and foes.
- [mtx](https://github.com/vic/mtx) is a Matrix chat client for the terminal, with helix and vim style keys.
- [gebed](https://github.com/vic/gebed) is a TUI on the web for managing your beads, because none of the existing web UIs worked with both databases I needed.
- [ircc](https://github.com/vic/ircc) is a local IRC-like chat for Claude Code sessions. Each session is a `#channel`, you make rooms, and agents on different projects can talk to each other instead of through me. It opens no network port, only unix sockets. Yes, I built a chat room for robots. They are better at it than I am :D
- [tinted-jjui](https://github.com/vic/tinted-jjui) has [jjui](https://github.com/idursun/jjui) themes made from base16 and base24 schemes.
- [leader](https://github.com/vic/leader) is a vim-style leader key for your `$SHELL`.
